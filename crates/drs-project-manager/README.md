# drs-project-manager

The Manager that saves, opens, and exports Projects.

For now it owns the start of the Project lifecycle alone: at startup it creates
the new, unsaved Project the editor opens on, with one Level named `Level 1`
holding one Layer named `Layer 1`, a Grid of 256 pixels per cell, and default
Bounds.

## Features

- `default`: nothing is enabled by default.
- `dev`: debug tooling for development.
